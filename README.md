# RemiDex

Plays BeetleBoy and BeetleCraft on RemiliaNET for you.

## Install

**Mac:** open Terminal, paste this, press Enter:
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/tremorbae/Remidex/main/get.sh)"
```



**Windows:** open PowerShell, paste this, press Enter:
```
irm https://raw.githubusercontent.com/tremorbae/Remidex/main/get.ps1 | iex
```

Then type `y`, and log in to RemiliaNET in the Chrome window that opens.

Your dashboard is at **http://remidex.localhost:8642**


## Remove

**Mac:** `~/RemiDex/install_browser.sh --uninstall`

**Windows:** `py $HOME\RemiDex\install_windows.py --uninstall`

---

Not made by Remilia. Your login stays on your computer.
